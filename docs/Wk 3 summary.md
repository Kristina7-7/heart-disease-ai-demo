# Week 3 Summary

## Objective

The goal of Week 3 was to interpret and compare machine learning models for heart disease prediction.

## Tasks Completed

- Created a Logistic Regression confusion matrix.
- Created a Random Forest confusion matrix.
- Visualized Logistic Regression coefficients.
- Visualized Random Forest feature importance.
- Compared the performance of Logistic Regression and Random Forest using Accuracy, Precision, Recall, and F1-score.
- Discussed the limitations of the project.
- Proposed future improvements.

## Key Findings

- Logistic Regression achieved a slightly higher accuracy than Random Forest on this dataset.
- Random Forest identified the most important clinical features used for prediction.
- Logistic Regression provided interpretable coefficients showing whether features increased or decreased the prediction.
- Both models had difficulty predicting the minority classes because the dataset is small and imbalanced.

## What I Learned

During this week, I learned how to interpret machine learning models instead of only measuring their accuracy. I also learned how to explain model predictions using confusion matrices, coefficient plots, and feature importance charts.
